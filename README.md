# Convite Interativo — Aysha

Projeto de convite em várias páginas para o tema Jardim Encantado.

## Estrutura
- `index.html` — abertura
- `jardim.html` — jardim interativo
- `historia.html` — história em 3 capítulos
- `data.html` — data
- `local.html` — local
- `presentes.html` — sugestões de presente
- `rsvp.html` — confirmação de presença
- `final.html` — encerramento
- `css/style.css` — estilos e responsividade
- `js/app.js` — interações e animações
- `assets/` — SVGs e elementos visuais
